# Как опубликовать Jarvis на GitHub Pages

1. Скачай архив сайта и распакуй его.
2. Открой репозиторий: https://github.com/Tandi345645321/JarvisAPP
3. Нажми **Add file → Upload files** и перетащи все файлы и папку `assets` из распакованной папки в корень репозитория.
4. Нажми **Commit changes**.
5. Перейди в **Settings → Pages**.
6. В **Build and deployment** выбери **Deploy from a branch**.
7. Выбери ветку **main** и папку **/(root)**, нажми **Save**.
8. После публикации открой: https://tandi345645321.github.io/JarvisAPP/

Если GitHub Pages предложит включить публикацию для репозитория, следуй подсказке в Settings → Pages.
